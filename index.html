一次最多 20 个文件。每个文件分别出一份报告，用来区分不同设备。单文件与展开扫描预算为 2 GiB。系统版本和电池相关的 plist 会读取；ZIP64、加密包和其他无关二进制仍不支持。

其他生成方式

也可以同时按下音量上、音量下和侧边键约一秒，感到短震动后松开。文件名仍是 sysdiagnose_日期_时间±时区_….tar.gz，体积通常是几百 MB，不是固定的 320 MiB。

Apple 官方诊断说明 ↗

不需要安装描述文件，也不要把完整诊断包交给服务器。本工具只提取受支持的硬件与电池字段。

供应商识别依据

「日志直接记录」表示文件中写出了厂商或型号文本。「资料对照」表示用部件代号前缀查本地数据表，可以关闭。

屏幕：G9N / G9P / G9Q → 三星显示，GH3 / GVC → LG，J5V / B02 / B03 → 京东方。电池：F5D → 惠州德赛，F8Y → 欣旺达，FG9 / F9Y → 新普科技。日志里直接写出的英文厂名会显示成对应中文名。没有收录的代号保持未识别，不编造档次。

手动功能检查

这些检查依靠实际观察，不能由日志或供应商名称代替。

屏幕与触控

进入纯色画面检查明显坏点或色块；不同亮度下的均匀性仍需你观察。

在下方拖动手指，观察轨迹是否连续。浏览器手势和边缘区域可能影响测试。

摄像头

主动点击后才会请求摄像头权限。画面不拍照、不上传；浏览器无法保证切换每一个物理镜头。

离线使用与隐私

在 Safari 分享菜单中「添加到主屏幕」。首次联网看到“离线资源已就绪”后，可尝试断网打开。系统可能清除网站缓存。

原始文件只在本地工作线程中读取，不发送、不持久化，也不会进入离线缓存。序列号默认遮盖。只有点击「保存到此设备」才在浏览器数据库保存脱敏结果，可以逐项删除；清除本次记录仅清空内存。

导出不包含完整日志、原始设备标识或完整部件序列号。文件中的时间、地区和容量等字段仍可能透露设备信息，分享前请检查。初次加载和更新会请求 GitHub Pages 的应用资源，托管方可能记录 IP 等访问元数据。
